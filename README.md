# NEXUS Assistant

Персональный ассистент для Windows 10 на C# и WPF. Поддерживает текстовые и голосовые команды, управление приложениями и папками, Яндекс Музыку и локальный диалог через Ollama.

## Запуск

Для запуска опубликованной версии нужен .NET 10 Desktop Runtime соответствующей архитектуры. Для сборки нужен .NET 10 SDK. Окно проверено на Windows 10 22H2, сборка 19045. [Установка .NET для Windows](https://learn.microsoft.com/en-us/dotnet/core/install/windows)

Готовая сборка находится в папке `dist`, если проект опубликован. Запустите `NexusAssistant.exe` и сохраните остальные файлы сборки рядом с ним. Одновременно работает один экземпляр приложения.

Из корня проекта можно собрать, запустить и опубликовать программу командами PowerShell.

~~~powershell
dotnet build -c Release
dotnet run --project NexusAssistant -c Release
dotnet publish NexusAssistant -c Release -o dist
~~~

## Команды

- «Нексус, открой Firefox», «Запусти Roblox Studio», «Открой настройки Windows». Для других приложений можно назвать ярлык из меню «Пуск», например «Открой приложение Visual Studio Code». Ярлыки ищутся по имени, без расширения.
- «Создай папку на рабочем столе». Ассистент запросит имя. Можно указать его сразу, например `Создай папку «Проект» на рабочем столе`.
- `Переименуй папку «Проект» в «Архив»`. Поддерживается уточнение исходного и нового имени. «Отмена» сбрасывает уточнение.
- «Открой Яндекс Музыку», «Включи Яндекс Музыку», «Переключи песню», «Верни предыдущий трек», «Поставь лайк», «Открой мои плейлисты», «Пауза», «Продолжи музыку».
- «Открой загрузки», «Открой мои документы», «Открой рабочий стол», «Открой этот компьютер», «Запусти Paint», «Открой диспетчер задач», «Покажи настройки звука», «Открой параметры дисплея».
- «Найди в интернете фотографии Сатурна» открывает поиск в браузере, выбранном в настройках. «Который час?» показывает локальное время и дату.

Поддерживаются русские формулировки и распространённые варианты названий. Команды для папок работают в каталоге рабочего стола текущего пользователя. Имена папок с пробелами и союзами удобно заключать в кавычки «…» или "…".

### Свои команды

В разделе «Команды» введите фразу, выберите действие и заполните появившееся поле. Можно открыть файл, папку, приложение или сайт, задать текст ответа или запустить поиск. Путь можно ввести вручную или выбрать в диалоге. Например, фразе «Привет» можно назначить ответ «Рад тебя видеть!».

Сохранённая фраза срабатывает при вводе в чат или после голосового распознавания. Сопоставление учитывает всю фразу, пропускает обращение «Нексус», лишние пробелы и знаки конца предложения. Своя команда с совпадающей фразой имеет приоритет над встроенной. Список можно изменить или очистить по одной записи. Он хранится локально в `commands.json`.

## Инструменты ПК

- «Температуры» показывает доступные датчики накопителей, NVIDIA и системных зон ACPI. Для подробных показаний процессора и видеокарты NEXUS может читать датчики запущенного LibreHardwareMonitor через WMI. [LibreHardwareMonitor](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor)
- Монитор нагрузки показывает ЦП, GPU и память. На открытой странице его можно обновлять каждые восемь секунд. Для поиска вредоносных программ доступны журнал и быстрая проверка Защитника Windows.
- «Анализ места» показывает крупные папки и файлы в корне выбранного диска. При достижении лимита времени или числа записей выводится частичный результат. Очистка корзины запрашивает системное подтверждение.
- В игровом режиме NEXUS повышает приоритет отслеживаемых игр и возвращает прежний приоритет при выключении. Укажите названия EXE игр через запятую. Для приложений из отдельного списка NEXUS запрашивает закрытие обычным способом после подтверждения. Счётчик времени сохраняется локально.
- Можно выбрать устройство вывода звука, замерить ICMP-пинг до указанного адреса и проверить загрузку и отдачу. Замер скорости использует до 10 МБ трафика. [Cloudflare Speed Test](https://developers.cloudflare.com/fundamentals/performance/test-speed/)

### Быстрый ввод

Нажмите **Ctrl + Alt + N**. В строке поверх окон введите, например, «открой вк», и нажмите **Enter**. **Escape** скрывает строку. Комбинацию можно сменить в «Инструментах ПК». С включённой комбинацией закрытие основного окна оставляет NEXUS в области уведомлений. Там же доступна кнопка «Быстрый ввод».

## Голос

Нажмите кнопку микрофона и произнесите одну фразу. Повторное нажатие отменяет запись или распознавание. Обращение «Нексус» в начале фразы необязательно. Микрофон использует устройство ввода по умолчанию.

Распознавание работает через классический движок Windows `ru-RU` либо локальный Whisper. Для Whisper создайте папку `Speech` в каталоге данных приложения. Скопируйте туда `whisper-cli.exe` с DLL из соответствующей сборки и многоязычную модель `ggml-base.bin`. При наличии обоих файлов приложение выбирает Whisper. Запись и расшифровка обрабатываются локально, временные файлы удаляются после распознавания. [whisper.cpp](https://github.com/ggml-org/whisper.cpp)

Для озвучивания включите соответствующую настройку и сохраните её. Синтез использует установленный русский голос SAPI. Свечение реагирует на уровень сигнала микрофона при прослушивании и на амплитуду синтезированной речи при воспроизведении.

## Яндекс Музыка

Яндекс Музыка и плейлисты открываются в браузере, выбранном в настройках. Для смены трека, паузы и лайка запустите трек во вкладке Яндекс Музыки. Ассистент обращается к элементам управления через Windows UI Automation в Firefox, Chrome, Edge или Brave. Доступность команд зависит от браузера и разметки плеера.

В «Настройках» можно задать имя для приветствия, выбрать браузер для команд и отдельно отключить звук переключателей. Нажмите «Сохранить настройки», чтобы применить выбор браузера и сохранить профиль.

## Управление ПК через Telegram

1. Создайте отдельного бота командой `/newbot` у официального [BotFather](https://t.me/BotFather).
2. В NEXUS откройте «Управление ПК», вставьте токен и нажмите «Подключить». Для запуска приложений добавьте их в список, например `Dota 2 = C:\Games\Dota 2\dota2.exe`. Можно выбрать файл кнопкой «Выбрать .exe…».
3. На телефоне откройте личный чат с созданным ботом и отправьте команду `/pair` с кодом из NEXUS. Код одноразовый и действует пять минут.

Бот покажет кнопки для снимка основного экрана, топа процессов по ЦП, списка приложений, окон и вкладок браузера. Для запуска можно написать `/open dota2` или «Открой Dota 2». Короткие опечатки допустимы, если подходит только одно имя. Для выбора используйте кнопки под списком или введите `/switch 2` для окна и `/tab 2` для вкладки. Номера действуют две минуты.

При включённом боте крестик скрывает NEXUS в области уведомлений. Дважды щёлкните значок NEXUS, чтобы вернуть окно. В разделе «Управление ПК» можно включить запуск NEXUS при входе в Windows. Для работы бота компьютеру нужны активный сеанс Windows и доступ к Telegram. Скриншоты и переключение окон требуют разблокированного рабочего стола. Вкладки определяются через интерфейс доступности Firefox и поддерживаемых Chromium-браузеров. Windows может ограничить вывод фонового окна на передний план. Токен шифруется средствами Windows для текущего пользователя. «Выключить» останавливает бота, «Отвязать телефон» сбрасывает доступ, а «Выйти из NEXUS» в меню значка завершает приложение. [Telegram Bot API](https://core.telegram.org/bots/api)

Чтобы передать NEXUS другому человеку, отправьте архив сборки целиком. Получатель распаковывает его в постоянную папку, запускает приложение, подключает свой токен BotFather и привязывает свой аккаунт. Один токен предназначен для одного работающего экземпляра NEXUS.

## Локальный чат и данные

Для свободного диалога запустите Ollama на `127.0.0.1:11434`, загрузите локальную модель и укажите её точное имя в настройках. Встроенные команды доступны при пустом поле модели. Ассистент передаёт Ollama до 12 предыдущих сообщений и текущий запрос. Выполнение системных действий остаётся в обработчике встроенных команд. [Ollama Chat API](https://docs.ollama.com/api/chat)

История и настройки хранятся в `%LOCALAPPDATA%\NexusAssistant`. Можно задать другой каталог переменной `NEXUS_ASSISTANT_DATA` перед запуском. История очищается в разделе «История» после подтверждения.

## Сцена

Изображение аккреционного диска строится локально. Таблица траекторий света в метрике Шварцшильда определяет, какую сторону диска видно по каждому лучу. Дифференциальное вращение, текстура и ореол рассчитываются отдельно. Анимация реагирует на голос и состояние ассистента. [Исследование линзирования и визуальных эффектов «Интерстеллара»](https://arxiv.org/abs/1502.03808)

## Проверки

~~~powershell
dotnet run --project NexusAssistant.Tests -c Release
dotnet run --project NexusAssistant.Tests -c Release -- --render --speech
~~~

Тесты работают с тестовыми папками и данными в `.nexus-test`. Маршрутизация команд запуска, музыки, голосового ввода и запросов Ollama проверяется с подменой соответствующих внешних сервисов. Флаг `--render` сохраняет отрисовку WPF для двух размеров окна. Флаг `--speech` дополнительно запускает проверку русского системного синтеза. Для неё требуется доступ к установленному голосу Windows.
